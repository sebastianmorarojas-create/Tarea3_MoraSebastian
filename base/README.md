# CA0204 · Tarea 3 · Base del docente

Se clona **dentro** de su proyecto, en la carpeta `base/`:

```bash
git clone https://github.com/PotoyJuarez/CA0204-Tarea3-base.git base
```

| Archivo | Para qué |
|:--|:--|
| `00_generar_base.R` | Genera sus datos y parámetros. Se llama desde `cod/01_datos.R` |
| `funciones_base.R` | Lo usa el script anterior. **No modificar** |
| `cantones.csv` | Catálogo de cantones (código, cantón, provincia) |
| `Plantilla_Tarea3.xlsx` | Cópiela a `excel/` y renómbrela `Tarea3_ApellidoNombre.xlsx` |
